# Fitted

## Frontend:

To start frontend run:
`cd client`
`npm install`
`npx expo start`

Make sure to add client/.env
 - EXPO_PUBLIC_SUPABASE_URL=
 - EXPO_PUBLIC_SUPABASE_KEY=
 - EXPO_PUBLIC_SERVER_URL=

## Backend:
To run background:

`cd server`
`npm install`
`npm run dev`

Make sure to add you server/.env keys for:
 - GEMINI_API_KEY=
 - SUPABASE_URL=
 - SUPABASE_SERVICE_KEY=
