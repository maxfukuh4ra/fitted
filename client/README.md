# Fitted Mobile (Expo)

Mobile client for Fitted, built with Expo and Expo Router.

## Getting Started

### Prerequisites

- Node.js 20+ and npm
- One of:
  - iOS Simulator (Xcode), or
  - Android Emulator (Android Studio), or
  - Expo Go on a physical device

### Install Dependencies

```bash
npm install
```

### Run the App

```bash
npx expo start
```

Then open the app using one of the options shown in the terminal:

- press `i` for iOS simulator
- press `a` for Android emulator
- scan the QR code with Expo Go

## Verification

Successful setup means:

- Metro starts without errors
- the auth screen loads without missing import or route errors
- authenticated navigation still reaches the main tab flow
